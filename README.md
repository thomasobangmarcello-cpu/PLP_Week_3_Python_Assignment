# PLP Python Week 3 - Grade Reporter & Bug Hunt

`grade_reporter.py` - Uses loops and conditions to calculate grades, pass/fail counts, and the average score.

`bug_hunt.py` - Finds and fixes three bugs in a while loop program that calculates the sum of numbers 1 to 5.

The hardest bug to find was the loop condition because it did not produce an error message. The program could run normally but give the wrong answer because `count < 5` stops the loop before number 5 is added. I knew something was wrong because the expected answer was 15, but the program produced a different result.
